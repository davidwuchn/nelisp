# Known-defect injections (tools/nelisp-gate-mutation.sh).
#
# Each row is: GATE | FILE | SED-EXPRESSION | WHAT IT BREAKS
#
# The row is applied with `sed -i', the gate is run, and the file is
# restored.  The gate MUST fail.  A gate that stays green with a real defect
# in front of it is not a gate, and on 2026-08-19 three of them were in
# exactly that state while printing PASS.
#
# Keep the injections small and obviously wrong.  A subtle one that a gate
# legitimately does not cover teaches nothing except to delete the row.
emacs-parity|scripts/nelisp-stdlib-prelude.el|s/^(defun regexp-quote (s)/(defun regexp-quote (s) (setq s (concat s "@"))/|regexp-quote appends a stray character
ns-gate|scripts/nelisp-stdlib-prelude.el|s/^(defun round (x \&optional div)/(defun round (x \&optional div) (setq x x)/|round diverges from its lisp/ mirror
# The replacement is GLOBAL on purpose.  The first version changed one
# occurrence of a name that appears ten times, so the name stayed covered and
# the gate correctly stayed green -- a weak injection reads as a broken gate.
# The injection has to remove a name the corpus mentions ONCE.  An earlier
# version renamed `regexp-quote', which the corpus has grown many uses of --
# the coverage count stayed above the baseline and the gate correctly stayed
# green, which reads as a broken gate.  `nbutlast' is mentioned once.
# The name has to be one the compat table LISTS and the corpus mentions
# ONCE.  Two earlier versions failed that: `regexp-quote' is mentioned many
# times (the count stayed above the floor), and `nbutlast' is not in the
# generated table at all (so it was never counted, and removing it changed
# nothing).  Both read as a broken gate when the gate was fine.
parity-coverage|test/nelisp-shadow-differential-cases.el|s/generate-new-buffer/ignore-me-not-a-name/g|a covered name stops being mentioned
prelude-toplevel-check|scripts/nelisp-stdlib-prelude.el|s/^(defun string-empty-p (s) (string-equal s ""))$/(defun string-empty-p (s) (string-equal s ""))\n  (nelisp--check-string s)/|a check lands outside a one-line defun
# The sed expression cannot use `|' -- it is this file's field separator.
prelude-toplevel-check|scripts/nelisp-stdlib-prelude.el|/^  (defun seq-length (seq) (length seq)))$/a\    (unless (sequencep seq) (signal (quote wrong-type-argument) (list (quote sequencep) seq)))|a check lands outside a one-line defun INSIDE an unless wrapper

# 2026-08-21 (this session): the five rows below cover the identity-pinning
# added to unsafe-inventory, ns-inventory, fallback-inventory and pkg-graph,
# plus generated-source-parse, which had no row at all.  Each is chosen so a
# bare COUNT would not have moved: the pinned identity changes (a new one
# appears, or an already-divergent pair's shape drifts) while the aggregate
# stays where it was, which is exactly the blind spot `parity-coverage' and
# `ns-gate' were caught in on 2026-08-21.
